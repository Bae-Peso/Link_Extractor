# Link Extractor

閲覧中のページから、指定したキーワードを含むリンクをまとめて抽出する Firefox 拡張機能です。

**インストール:** [Firefox Add-ons（AMO）](https://addons.mozilla.org/firefox/addon/link_extractor/)

例えば、Google で「MacBook Pro」を検索した結果ページで `apple.co` と入力すると、ページ内の Apple 関連のリンクだけを一覧にして、まとめて新しいタブで開けます。

## 主な機能

- キーワード（例: `google.com`）を含むリンクを、現在のタブから抽出
  - `<a href>` のリンクと、本文中にテキストとして書かれた URL の両方が対象
- 結果を 1 行ずつ表示（重複は除外）、件数を表示
  - コピーは結果欄から直接可能
- 抽出したリンクをすべて新しいタブで開く
  - 10 件を超える場合は警告を表示し、もう一度押したときだけ開く
  - 開いている途中は進捗（`Opened 5 of 23 links`）を表示

## インストール

[Firefox Add-ons のページ](https://addons.mozilla.org/firefox/addon/link_extractor/) から「Firefox へ追加」でインストールできます。

**審査に何日かかかるため、表示されていない可能性もあります。その場合は`開発版の読み込み`の方法を利用してください。**

## 使い方

1. ツールバーのアイコンをクリック
2. キーワード（例: `apple.co`）を入力して「Extract」
3. 必要に応じて結果をコピー、または「Open all」で一括オープン

## 開発版の読み込み

1. Firefox のアドレスバーに `about:debugging` と入力
2. 「この Firefox」→「一時的なアドオンを読み込む」
3. このフォルダの `manifest.json` を選択

※ 一時的なアドオンは Firefox を終了すると消えるため、再起動後はもう一度読み込みます。

## 設計で意識したこと

- **最小権限**
  `<all_urls>` ではなく `activeTab` のみを使用しています。この拡張はユーザーがボタンを押したときだけ動くため、押したタブにだけ一時的に権限が付与される `activeTab` で十分だと判断しました。インストール時に「すべてのサイトのデータへのアクセス」の警告も出ません。
- **全角・半角の空白への対応**
  本文の分割には正規表現 `\s` を使い、半角スペースだけでなく全角スペース・タブ・改行もまとめて区切りとして扱っています。URL に使われない `「」<>"` も区切りに含めています。
- **重複除外の精度**
  同じリンクが `https://example.com/a`（href）と `example.com/a`（本文）のように別の形で出てくるため、`http://` `https://` を外してから `Set` で重複を除外しています。
- **入力値の安全な受け渡し**
  キーワードはページ側に注入するコード文字列に埋め込むため、`JSON.stringify` でエスケープし、引用符が入力されてもコードが壊れないようにしています。
- **誤操作の防止**
  空のキーワードは受け付けません（空文字はすべての文字列に一致してしまうため）。また、大量のタブを一度に開かないよう、10 件超は 2 回押しの確認方式にしました。
- **タブを開く処理**
  タブは `active: false` で背景に開きます（フォーカスが移るとポップアップが閉じ、処理が途中で止まるため）。サーバー側の制限（429 エラー）を避けるため、1 件ごとに 150ms の間隔を空けています。
- **入れなかった機能**
  当初は txt 保存機能も予定していましたが、結果欄から直接コピーできるため、実際の利用場面では不要と判断して外しました。

## 制限事項

- **キーワードは部分一致**
  リンクかどうかに関係なく、キーワードを含む文字列はすべて抽出されます。例えば `apple.co.jp` を探すつもりで `apple` と入力すると、本文中の単なる単語 `apple` も結果に含まれます。ドメインまで含めて入力（`apple.co.jp`）すると精度が上がります。
- **新しいタブは常に `https://` で開く**
  重複除外のためにスキームを外しているため、`http://` にしか対応していないサイトは開けません。
- **末尾の記号**
  本文中の URL の直後に `,` `)` などが続く場合、その記号ごと抽出されることがあります（URL 自体に含まれ得る記号のため、区切りにはしていません）。
- **対象外のページ・要素**
  `about:` ページや addons.mozilla.org などでは Firefox の仕様上動作しません。また、iframe 内のリンクや、スクロールして初めて読み込まれるリンクは対象外です。
- **開いている途中でポップアップを閉じると中断**
  件数が多い場合は、完了表示が出るまでポップアップを閉じないでください。

## 今後の改善案

- 元のスキーム（http / https）を `Map` で保持し、開くときに元の URL を使う
- 本文からの抽出は `.` や `/` を含む文字列に限定し、単なる単語を除外する
- 結果欄を編集可能にし、不要な行を消してから開けるようにする
- 末尾の記号を除去する

## 実装の分担

| ファイル | 内容 | 作成 |
|---|---|---|
| `extract.js` | ページ内のリンク抽出・重複除外 | 自分で実装 |
| `popup.js` | 注入・結果表示・タブを開く処理・警告 | 自分で実装 |
| `manifest.json` / `popup.html` / `popup.css` | 骨組み・見た目 | 生成 AI で作成し、調整 |

他の制作物は生成 AI を中心に実装したため、この拡張機能ではコアのロジックを自分の手で書くことを目標にしました。

## 動作環境

- Firefox（Manifest V2）
